# نگاه مدیا — سایت شرکتی و پنل مدیریت PHP / MySQL

یک وب‌سایت راست‌چین فارسی برای استودیوی تبلیغات و بازاریابی «نگاه مدیا»؛ با حال‌وهوای مینیمال ایرانی، نقوش هندسی الهام‌گرفته از گره‌چینی و ترکیب رنگ فیروزه‌ای، آجری، زعفرانی و کاغذی. این پروژه با PHP و MySQL نوشته شده و برای اجرا در ریشهٔ یک وب‌سایت IIS آماده شده است.

## نیازمندی‌ها

- IIS 10 یا بالاتر و PHP **۸٫۱+** به‌صورت FastCGI
- MySQL 5.7+ یا MariaDB 10.4+
- افزونه‌های PHP: `PDO`, `pdo_mysql`, `fileinfo` و `mbstring` (برای سازگاری بهتر با متن فارسی)
- دسترسی نوشتن برای کاربر Application Pool روی پوشهٔ `uploads/`
- برای خود سایت به Composer یا URL Rewrite نیاز نیست.

## نصب روی Windows / IIS

۱. فایل‌های پروژه را در پوشهٔ فیزیکی سایت کپی کنید و آن پوشه را در IIS به‌عنوان **ریشهٔ سایت** تنظیم کنید. در Application Pool از گزینهٔ **No Managed Code** استفاده کنید. PHP باید از قبل در IIS با FastCGI ثبت شده باشد.

۲. یک پایگاه داده و کاربر اختصاصی بسازید. نمونهٔ دستورها در MySQL:

```sql
CREATE DATABASE negaah_media CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'negaah_user'@'127.0.0.1' IDENTIFIED BY 'یک-رمز-قوی-و-منحصر-به-فرد';
GRANT ALL PRIVILEGES ON negaah_media.* TO 'negaah_user'@'127.0.0.1';
FLUSH PRIVILEGES;
```

سپس فایل `database/schema.sql` را روی همین پایگاه داده Import کنید. جدول مدیران ساخته می‌شود، اما هیچ حساب یا رمز پیش‌فرضی در فایل‌ها وجود ندارد.

۳. از `app/config.local.php.example` یک کپی با نام `app/config.local.php` بسازید و مشخصات اتصال MySQL را در آن وارد کنید. این فایل در Git نادیده گرفته شده و در IIS نیز از دسترسی مستقیم وب مسدود است.

۴. به کاربر **IIS AppPool\نام‌استخر** برای `uploads/` دسترسی **Modify** بدهید؛ به سایر فایل‌ها فقط دسترسی خواندن لازم است. در `php.ini` مقدارهای `upload_max_filesize=4M` و `post_max_size=5M` را تنظیم کنید. محدودیت خود سایت ۴ مگابایت است و فقط JPG، PNG، WEBP و GIF پذیرفته می‌شوند.

۵. باز کنید:

```text
https://your-domain.example/admin/setup.php
```

نام کاربری و رمز عبور مدیر اصلی را خودتان بسازید. رمز باید حداقل ۱۲ نویسه داشته باشد. بعد از ساخت نخستین مدیر، صفحهٔ راه‌اندازی خودکار غیرفعال می‌شود. برای ورودهای بعدی از `/admin/login.php` استفاده کنید.

فایل `web.config`، `index.php` را به‌عنوان صفحهٔ پیش‌فرض انتخاب می‌کند، مسیرهای داخلی `app/` و `database/` را از درخواست مستقیم وب می‌بندد و چند سرآیند امنیتی اضافه می‌کند. فایل `uploads/web.config` هم اجرای اسکریپت در پوشهٔ رسانه را مسدود می‌کند. در صورت نصب PHP در IIS، Handler Mapping باید روی سرور فعال باشد؛ این بخش تنظیم سرور است و داخل خود سایت قابل تعریف نیست.

## چه چیزهایی از پنل قابل مدیریت است؟

پنل `/admin/` شامل این بخش‌هاست:

- **محتوای سایت:** متن و پیوند همهٔ بخش‌های صفحهٔ اصلی، آمارها، مراحل همکاری، اطلاعات تماس، شبکه‌های اجتماعی و ۵ رنگ اصلی سایت؛ همراه با بارگذاری تصویر آغازین.
- **خدمات:** افزودن، ویرایش، ترتیب‌دهی، انتشار/پیش‌نویس و حذف.
- **نمونه‌کارها:** عنوان و شرح، دسته‌بندی، برچسب تصویر، تصویر اختصاصی، رنگ‌مایه و ترتیب نمایش.
- **دیدگاه‌ها و دفترچه نگاه:** مدیریت نقل‌قول‌ها و مقاله‌ها، پیوند انگلیسی یکتا، تصویر و تاریخ انتشار.
- **درخواست‌های تماس:** مشاهدهٔ پیام، اطلاعات تماس، ثبت وضعیت پیگیری یا حذف درخواست.
- **حساب مدیران:** تغییر نام کاربری یا رمز، افزودن همکار و حذف حساب‌های دیگر. هر مدیر دسترسی کامل دارد و رمزها با `password_hash()` نگهداری می‌شوند.

فرم تماس سایت درخواست‌ها را در جدول `inquiries` ذخیره می‌کند. صفحات مدیریتی از prepared statements، نشست امن، توکن CSRF، محدودیت تلاش ورود، اعتبارسنجی تصویر و escape خروجی استفاده می‌کنند.

## محتوای نمونه

چند خدمت، پروژه و دیدگاه برای نمایش اولیه در دیتابیس قرار داده شده‌اند. نمونه‌کارها با برچسب «پروژه مفهومی» مشخص‌اند و نقل‌قول‌های پیش‌فرض نیز نمایشی هستند؛ پیش از انتشار عمومی، آن‌ها را با نمونه‌کارها، اطلاعات و رضایت واقعی جایگزین کنید یا از حالت انتشار خارج کنید. اگر اتصال MySQL هنوز تنظیم نشده باشد، صفحهٔ اصلی با محتوای پیش‌فرض بالا می‌آید؛ برای فرم تماس و مدیریت محتوا اتصال دیتابیس لازم است.

## نکته‌های انتشار

- برای سایت HTTPS را فعال کنید و رمز دیتابیس و مدیر را یکتا نگه دارید.
- از پایگاه داده و پوشهٔ `uploads/` نسخهٔ پشتیبان منظم بگیرید.
- پوشهٔ `uploads/` را به‌صورت عمومی قابل نوشتن نکنید؛ مجوز Modify فقط برای Application Pool باشد.
- دامنه، شماره تماس، ایمیل، آدرس و لینک شبکه‌های اجتماعی از پنل قابل تغییر هستند. فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در شبکه‌های محدود، فونت جایگزین سیستم استفاده خواهد شد.
- رنگ‌ها با الهام از رنگ‌های ایرانی انتخاب شده‌اند و از پنل قابل سفارشی‌سازی‌اند.
