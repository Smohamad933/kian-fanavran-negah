# نگاه مدیا — سایت شرکتی و پنل مدیریت PHP / MySQL

یک وب‌سایت راست‌چین فارسی برای استودیوی تبلیغات و بازاریابی «نگاه مدیا»؛ با حال‌وهوای مینیمال ایرانی، نقوش هندسی الهام‌گرفته از گره‌چینی و ترکیب رنگ فیروزه‌ای، آجری، زعفرانی و کاغذی. این پروژه با PHP و MySQL نوشته شده و برای اجرا در ریشهٔ یک وب‌سایت IIS آماده شده است.

## نیازمندی‌ها

- IIS 10 یا بالاتر، قابلیت CGI/FastCGI و ماژول **IIS URL Rewrite 2**
- PHP **۸٫۱+** به‌صورت FastCGI و MySQL 5.7+ یا MariaDB 10.4+
- افزونه‌های PHP: `PDO`, `pdo_mysql`, `fileinfo` و `mbstring` (برای سازگاری بهتر با متن فارسی). برای اتصال Search Console افزونهٔ `openssl` و تنظیم `allow_url_fopen=On` نیز لازم است.
- دسترسی نوشتن برای کاربر Application Pool روی پوشهٔ `uploads/`
- برای اجرای سایت به Composer نیاز نیست؛ URL Rewrite برای مسیرهای تمیز برند و یادداشت و front controller استفاده می‌شود.

## نصب روی Windows / IIS

۱. فایل‌های پروژه را در پوشهٔ فیزیکی سایت کپی کنید و آن پوشه را در IIS به‌عنوان **ریشهٔ سایت** تنظیم کنید. در Application Pool از گزینهٔ **No Managed Code** استفاده کنید و قابلیت CGI/FastCGI و ماژول IIS URL Rewrite 2 را نصب کنید. در `web.config` مسیر `C:\php\php-cgi.exe` هم در بخش `fastCgi` و هم در PHP Handler Mapping آمده است؛ اگر PHP در مسیر دیگری نصب شده، هر دو را با مسیر واقعی جایگزین کنید. اگر میزبانی شما FastCGI را فقط در سطح سرور مدیریت می‌کند یا تنظیمات `web.config` را قفل کرده، ثبت FastCGI/Handler Mapping را از IIS Manager یا مدیر میزبان انجام دهید.

۲. یک پایگاه دادهٔ MySQL و کاربر اختصاصی بسازید (در هاست اشتراکی معمولاً از کنترل‌پنل هاست). نصب‌کننده تلاش می‌کند پایگاه داده را بسازد؛ اگر کاربر هاست اجازهٔ `CREATE DATABASE` نداشته باشد، نام دیتابیسِ ازپیش‌ساخته را وارد کنید. کاربر باید روی همان دیتابیس اجازهٔ ساخت جدول داشته باشد؛ برای افزودن ستون به نصب قبلی، دسترسی `ALTER TABLE` هم لازم است.

۳. موقتاً به کاربر **IIS AppPool\نام‌استخر** برای پوشهٔ `app/` اجازهٔ نوشتن بدهید، سپس باز کنید:

```text
https://your-domain.example/install.php
```

اطلاعات MySQL را وارد کنید. نصب‌کننده `database/schema.sql` را اجرا می‌کند، تنظیم اتصال را در `app/config.local.php` می‌نویسد و با `app/installed.lock` صفحهٔ نصب را قفل می‌کند. پس از نصب، دسترسی نوشتن پوشهٔ `app/` را بردارید. اگر ترجیح می‌دهید نصب دستی انجام دهید، فایل `database/schema.sql` را در MySQL Import و `app/config.local.php.example` را با مشخصات خودتان به `app/config.local.php` کپی کنید. فایل تنظیمات محلی در Git نادیده گرفته شده و در IIS از درخواست مستقیم وب مسدود است.

۴. از `https://your-domain.example/admin/setup.php` نام کاربری و رمز عبور مدیر اصلی را خودتان بسازید. رمز باید حداقل ۱۲ نویسه داشته باشد. بعد از ساخت نخستین مدیر، صفحهٔ ساخت مدیر دوباره قابل استفاده نیست؛ برای ورودهای بعدی از `/admin/login.php` استفاده کنید.

۵. به کاربر **IIS AppPool\نام‌استخر** برای `uploads/` دسترسی **Modify** بدهید؛ به سایر فایل‌ها فقط دسترسی خواندن لازم است. در `php.ini` دست‌کم `upload_max_filesize=100M`، `post_max_size=125M`، `max_file_uploads=20`، `max_execution_time=180` و `max_input_time=180` را تنظیم کنید. تصویرها تا ۴ مگابایت، ویدیوهای MP4/WEBM تا ۱۰۰ مگابایت و فونت‌ها تا ۸ مگابایت پذیرفته می‌شوند؛ هر پست اسلایدی حداکثر ۱۰ تصویر دارد و IIS سقف درخواست را روی ۱۲۰ MiB تنظیم می‌کند.

فایل `web.config`، PHP FastCGI و صفحهٔ پیش‌فرض `index.php` را تنظیم می‌کند، مسیرهای داخلی `app/`، `database/` و `views/` را می‌بندد، `/brands`، `/brand/{slug}`، `/article/{slug}`، `/sitemap.xml` و `/robots.txt` را بازنویسی می‌کند و مسیرهای ناشناخته را به front controller می‌فرستد. برای این قوانین، URL Rewrite 2 باید نصب باشد؛ CGI/FastCGI و ماژول‌های فشرده‌سازی IIS نیز باید فعال باشند و اگر بخش‌های تنظیمات در میزبان قفل شده‌اند، مدیر IIS باید آن‌ها را باز یا در سطح سرور پیکربندی کند. نوع MIME فایل‌های CSS و JavaScript نیز در `web.config` صریحاً تنظیم شده و نشانی این فایل‌ها با زمان آخرین تغییر نسخه‌گذاری می‌شود تا مرورگر از نسخهٔ cache‌شدهٔ قدیمی استفاده نکند. فایل `uploads/web.config` اجرای اسکریپت در پوشهٔ رسانه را مسدود می‌کند. اگر دیتابیس از قبل نصب شده، اجرای دوبارهٔ `database/schema.sql` دستهٔ برند، تصویر پیش‌نمایش، فیلدهای سئو برای برند و مقاله، جدول اسلایدها و مهاجرت‌های نسبت رسانه را اضافه می‌کند؛ دسته‌بندی اولیهٔ برندهای پیش‌فرض فقط یک‌بار انجام می‌شود و انتخاب‌های بعدی مدیر حفظ می‌شوند.

## چه چیزهایی از پنل قابل مدیریت است؟

پنل `/admin/` شامل این بخش‌هاست:

- **محتوای سایت:** متن و پیوند بخش‌های صفحهٔ اصلی، اطلاعات تماس و رنگ‌های اصلی؛ همراه با بارگذاری تصویر آغازین و فونت دلخواه WOFF2/WOFF/TTF/OTF. نمایش پیوند ورود مدیر و ZIP سورس در فوتر را می‌توان روشن/خاموش کرد؛ اعتبار «کیان فناوران نگاه» نیز قابل نمایش/حذف و لینک‌دارکردن است و URL ZIP از پنل قابل ویرایش می‌ماند.
- **برندهای همکار:** فهرست اولیهٔ ۳۲ برند به ترتیب درخواستی و صفحهٔ مستقل برای هرکدام؛ در آرشیو، پنج گزینهٔ «همه» و چهار دستهٔ اصلی «مراکز فرهنگی و آموزشی»، «شرکت‌ها و کسب‌وکارها»، «نهادهای دولتی، عمومی و اجتماعی» و «هنر، رسانه و رویداد» فیلتر را بدون نیاز به JavaScript انجام می‌دهند. دستهٔ هر برند از پنل تعیین می‌شود. تصویر پیش‌نمایش افقی با نسبت پیشنهادی ۳:۱ برای کارت آرشیو برندها تنظیم می‌شود؛ دیوار لوگوی صفحهٔ خانه از همهٔ برندهای منتشرشده تشکیل می‌شود، ۱۰ جایگاه را در دو ردیف پنج‌تایی نشان می‌دهد و لوگوها را یکی‌یکی از فهرست می‌چرخاند. گزینهٔ «اولویت نمایش در دیوار خانه» تعیین می‌کند کدام برندها در شروع زودتر دیده شوند. تصویر پیش‌نمایش کارت آرشیو، جدا از لوگوی برند است. معرفی و نظر تأییدشده نیز از پنل مدیریت می‌شود.
- **آرشیو رسانهٔ برندها:** بارگذاری تصویر یا ویدیو، درج عنوان و توضیح و انتخاب کاور با نسبت‌های ۱۶:۹، ۹:۱۶، ۱:۱ یا ۴:۵؛ نسبت پیش‌فرض پست‌های تازه ۴:۵ است. برای هر پست تصویری حداکثر ۱۰ اسلاید بارگذاری کنید و در فرم ویرایش با کشیدن و رهاکردن ترتیب اسلایدها را عوض کنید. صفحهٔ برند کنترل اسلاید، نقطه‌شمار، شماره و swipe موبایل دارد.
- **خدمات و نمونه‌کارها:** افزودن، ویرایش، ترتیب‌دهی، انتشار/پیش‌نویس و حذف؛ همراه با دسته‌بندی، تصویر اختصاصی و رنگ‌مایه.
- **دیدگاه‌ها و دفترچه نگاه:** مدیریت نقل‌قول‌های واقعی و مقاله‌ها، پیوند انگلیسی یکتا، تصویر و تاریخ انتشار.
- **درخواست‌های تماس:** مشاهدهٔ پیام، اطلاعات تماس، ثبت وضعیت پیگیری یا حذف درخواست.
- **حساب مدیران:** تغییر نام کاربری یا رمز، افزودن همکار و حذف حساب‌های دیگر. هر مدیر دسترسی کامل دارد و رمزها با `password_hash()` نگهداری می‌شوند.

فرم تماس سایت درخواست‌ها را در جدول `inquiries` ذخیره می‌کند. صفحات مدیریتی از prepared statements، نشست امن، توکن CSRF، محدودیت تلاش ورود، اعتبارسنجی تصویر و escape خروجی استفاده می‌کنند.

## تنظیم سئو و Google Search Console

در پنل `/admin/?page=seo` نشانی اصلی HTTPS، عنوان و توضیح صفحهٔ اصلی، عبارت‌های هدف و کد تأیید HTML گوگل را ثبت کنید. برای مقاله‌ها و صفحه‌های برند نیز فیلد عنوان سئو، توضیح یکتا و عبارت‌های هدف اضافه شده است. عبارت‌های هدف راهنمای نگارش و تحلیل‌اند؛ در صفحه به‌صورت متای `keywords` چاپ نمی‌شوند، چون Google این متا را برای رتبه‌بندی استفاده نمی‌کند. عنوان و توضیح به‌تنهایی رتبه را تضمین نمی‌کند؛ محتوای مفید و مرتبط لازم است.

نقشهٔ سایت خودکار در `/sitemap.xml` و قوانین خزش در `/robots.txt` ساخته می‌شوند. دامنهٔ اصلی را ابتدا در صفحهٔ سئو ذخیره کنید، سپس نشانی sitemap را در Search Console ثبت کنید. اجرای دوبارهٔ `database/schema.sql` ستون‌های عنوان/توضیح سئو و عبارت‌های هدف را به جدول‌های قدیمی مقاله و برند اضافه می‌کند و محتوای قبلی را بازنویسی نمی‌کند.

برای تأیید مالکیت، در Search Console یک **URL-prefix property** بسازید، روش **HTML tag** را انتخاب کنید و فقط مقدار `content` را در پنل وارد و ذخیره کنید؛ سپس به Search Console برگردید و **Verify** را بزنید. پنل تگ را در `<head>` صفحهٔ اصلی می‌گذارد. برای Domain property باید تأیید DNS را در سرویس دامنه انجام دهید.

اتصال گزارش Search Console اختیاری و فقط‌خواندنی است. در Google Cloud، Search Console API را فعال کنید و یک OAuth client از نوع Web application بسازید. دامنه را در پنل ذخیره کنید، نشانی بازگشت نمایش‌داده‌شده را دقیقاً در Authorized redirect URIs وارد کنید و سپس این مقادیر را داخل آرایهٔ `return` فایل محلی و نادیده‌گرفته‌شدهٔ `app/config.local.php` قرار دهید (کلیدها را به تنظیمات فعلی دیتابیس اضافه کنید، نه اینکه آن‌ها را جایگزین کنید):

```php
'gsc_client_id' => '...apps.googleusercontent.com',
'gsc_client_secret' => 'مقدار محرمانه از Google Cloud',
'gsc_token_encryption_key' => 'کلید تصادفی حداقل ۳۲ نویسه‌ای',
```

برای ساخت کلید رمزگذاری تصادفی روی سرور از `openssl rand -hex 32` استفاده کنید. توکن Refresh در دیتابیس با AES-256-GCM رمز می‌شود؛ کلید رمزگذاری و Client Secret را در Git یا گفتگو منتشر نکنید. سرور باید افزونهٔ PHP OpenSSL و دسترسی خروجی HTTPS داشته باشد؛ برای ارسال درخواست‌های API نیز `allow_url_fopen=On` لازم است. حسابی که در پنل متصل می‌کنید باید به property تأییدشده دسترسی داشته باشد. گزارش پنل عبارت جست‌وجو، صفحه، کلیک، نمایش، CTR و جایگاه میانگین را برای ۲۸ روز کامل اخیر (با سه روز فاصله برای کامل‌شدن داده‌ها) نشان می‌دهد؛ پیشنهادهای بهبود، تضمین رتبه نیستند.

## محتوای نمونه

خدمت‌ها و پروژه‌های آغازین نمونه‌اند و پروژه‌های مفهومی با همین برچسب مشخص می‌شوند. دیدگاه ساختگی پیش‌فرض منتشر نمی‌شود؛ فهرست ۳۲ برند برای آماده‌سازی صفحه‌ها ثبت شده، اما لوگو، شرح، آرشیو رسانه و نقل‌قول واقعی خالی‌اند تا مدیر آن‌ها را با اطلاعات مجاز تکمیل کند. اجرای دوبارهٔ `database/schema.sql` دیدگاه‌های آزمایشی قدیمی را از انتشار خارج می‌کند. اگر اتصال MySQL برقرار نباشد، صفحهٔ اصلی و صفحه‌های برند با داده‌های اولیهٔ بدون دیتابیس نمایش داده می‌شوند؛ پنل و فرم تماس برای کارکرد کامل به MySQL نیاز دارند.

## نکته‌های انتشار

- برای سایت HTTPS را فعال کنید و رمز دیتابیس و مدیر را یکتا نگه دارید.
- از پایگاه داده و پوشهٔ `uploads/` نسخهٔ پشتیبان منظم بگیرید.
- پوشهٔ `uploads/` را به‌صورت عمومی قابل نوشتن نکنید؛ مجوز Modify فقط برای Application Pool باشد.
- دامنه، شماره تماس، ایمیل، آدرس و لینک شبکه‌های اجتماعی از پنل قابل تغییر هستند. فونت پیش‌فرض Vazirmatn از Google Fonts بارگیری می‌شود؛ مدیر می‌تواند از پنل فونت اختصاصی بارگذاری کند و در شبکه‌های محدود، فونت جایگزین سیستم استفاده خواهد شد.

- رنگ‌ها با الهام از رنگ‌های ایرانی انتخاب شده‌اند و از پنل قابل سفارشی‌سازی‌اند.
